# Происхождение компонентов

Этот репозиторий собирает прикладной комплект для конкретной debug-прошивки. Общая лицензия на все файлы не назначается: права и условия сторонних компонентов сохраняются за их авторами.

| Компонент | Происхождение и ограничения |
| --- | --- |
| Debug-BIN WS7100-20 10.0.5.26 | Имеющийся исходный файл 2021 года, распространяемый отдельно в релизе; в этой работе не пересобирался и не патчился. Не является дампом пользовательского роутера. Проприетарная прошивка Huawei. |
| `xray.gz` | Community-пакет `ax3-awg31-v9.1.4-xray.tar`, заявленная версия Xray 26.9.8 с TUN/gVisor и XHTTP. Полного патча автора этой сборки нет. |
| `ax3-gunzip`, `httpd`, `dnsmasq`, `df`, `cacert.pem` | Готовые компоненты исходного community-комплекта. Деревья исходников их конкретных сборок здесь не представлены. |
| `xd20-ui-*.js` | Модифицированные штатные assets debug26 для дополнительного маршрута и пункта меню. |
| `ax3-manager` | Собран из приложенных Go-исходников с `-trimpath -ldflags "-s -w"` и локальным патчем Linux netpoll. Фиктивные данные в тестах не являются доступом к VPN. |
| `ax3-sync` | Минимальный ARM EABI5 helper `sync`/`exit`; генератор исходного ELF приложен. |
