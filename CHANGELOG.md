# Изменения

## 1.0.0 — 2026-10-19

Первая публикация текущего комплекта для HONOR XD20.

- Включены восемь файлов обновления панели, установленного 19 октября: `ax3-manager`, четыре контроллера shell, два CGI и HTML панели.
- Вкладка «Система», сведения о памяти и HWID, экспорт/импорт настроек.
- Автообновление подписок и массовая TCP-проверка серверов.
- Обработка привязки подписки к устройству и увеличенный предел ipset.
- Исходники менеджера, тесты и инструкция пересборки с патчем Go netpoll.
- Отдельные инструкции первой установки и обновления работающей системы.
- Публичный список доменов заменён демонстрационным `example.com`; реальные профили, ключи, подписки и данные входа не включены.

Проверено обновление работающего устройства, выход через VPN, DNS, сохранение доменов, обновление подписок, массовая проверка серверов и отображение панели. `go test`, `go vet` и проверки JavaScript выполнены для публикуемого дерева. Режим inverse и перезагрузка после последнего обновления не проверены.
