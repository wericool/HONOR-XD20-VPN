# VPN для HONOR Router 3 XD20

Xray на роутере: выбранные сайты идут через VPN, остальные — через провайдера. Отдельная русская панель позволяет менять серверы, обновлять подписки и управлять списком сайтов. Работает для основной Wi-Fi и проводной сети.

**Версия 1.0.0 от 19 октября 2026 года.** Это текущая версия панели и скриптов, установленная и проверенная на одном HONOR XD20. Восемь обновлённых файлов совпадают с проверенным комплектом обновления; остальные рабочие программы сверены с резервной копией установки. Прежний ZIP не использовался как источник релиза.

## Скачать

Открой [последний релиз](https://github.com/wericool/HONOR-XD20-VPN/releases/latest):

- `HONOR_XD20_VPN-v1.0.0.zip` — программы, панель, исходники менеджера и инструкции.
- `WS7100-20_10.0.5.26_main_debug.bin` — исходный debug-образ, отдельный от VPN-комплекта.
- `SHA256SUMS.txt` — контрольные суммы файлов релиза.

**VPN-комплект не является образом для кнопки «Обновить прошивку».** BIN устанавливается штатным модельным способом, а программы VPN переносятся в Linux уже подготовленного роутера. Если подходящая debug-прошивка и VPN уже установлены, повторно прошивать BIN не нужно.

## Совместимость

Проверено: **HONOR Router 3 XD20**, debug26 на базе WS7100-20 10.0.5.26, ARMv7, Linux 4.4.197. Скрипты рассчитаны на LAN `192.168.3.1/24`, JFFS2 `/data` на `/dev/mtdblock12` и `/patch` на `/dev/mtdblock23`.

Название HUAWEI в имени BIN не делает образ подходящим для любого AX3. Другие модели, аппаратные ревизии, подсети и разметки требуют отдельной проверки. До прошивки нужны резервная копия настроек и подходящий способ восстановления. Если штатный интерфейс отвергает BIN, не обходи проверку записью во flash.

## Установка

1. Прочти [подробный гайд](docs/GUIDE.txt): совместимость, debug-прошивка, диагностика, передача, первый запуск, пробные маршруты и автозапуск.
2. Для первой установки укажи свои домены в `domain.lst`. В публикации находится только `example.com`; пользовательского списка нет.
3. Запусти `python prepare-private.py` в интерактивном терминале и подготовь собственный начальный VLESS TCP/TLS профиль и собственный вход панели. Генератор не поддерживает первоначальный REALITY/XHTTP/WS/gRPC профиль; неподдерживаемые параметры он отвергает.
4. Переноси файлы по [списку команд](transfer-commands.example.txt), затем проверяй VPN до включения автозапуска.

Для уже работающей установки используй [инструкцию обновления](UPDATE.md). Не запускай повторно установщики overlay и не перезаписывай рабочий реестр через `seed`.

Панель после установки: `http://192.168.3.1:8088/`. Вход создаётся пользователем отдельно от штатного входа HONOR. Готовых логинов, паролей, подписок и ключей здесь нет.

## Что умеет панель

- Список доменов, управление VPN и сохранение состояния включения.
- Несколько подписок и ручные профили, последовательное переключение с возвратом при неудаче.
- Обновление подписок вручную и по расписанию, массовая проверка TCP-задержки.
- Вкладка «Система»: свободная память, HWID для провайдера, экспорт и импорт настроек.
- Светлая и тёмная темы; отдельный вход; необязательная кнопка в штатном меню HONOR.

Исходники также содержат режим «Всё через VPN, кроме…». Его работа на устройстве не проверена. Не воспринимай наличие переключателя как подтверждение испытаний.

## Что проверено

На работающем XD20 установлены и обратно прочитаны все восемь файлов обновления. Проверены синтаксис shell/CGI, версия менеджера, сохранение списка доменов, обновление подписок, массовая проверка серверов, DNS, HTTPS-выход через VPN с проверкой TLS и трафик компьютера через `xray0`. Отображение обновлённой панели подтверждено пользователем. Для исходников текущей публикации выполнены `go test` и `go vet`.

Чистая установка этого публичного ZIP на втором устройстве, перезагрузка именно после последнего обновления, длительная нагрузка и все варианты профилей не проверены. Скорость не измерялась.

## Приватность

Публикация собрана по явному списку файлов. Рабочие конфиги, подписки, ключи, пароли, пользовательский HWID, журналы и резервные копии исключены. `domain.lst` содержит только демонстрационный домен, `ip.lst` — только комментарий. Профили в Go-тестах фиктивные.

Созданная у тебя папка `reader-private`, экспорт настроек панели и логи могут содержать секреты. Не добавляй их в GitHub и не оставляй в каталоге временного HTTP-сервера после передачи. Telnet debug-прошивки даёт административный доступ: не открывай его в интернет. Панель использует HTTP Basic, поэтому рассчитана на доверенную локальную сеть.
